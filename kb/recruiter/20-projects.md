# Selected work

Case studies from his portfolio. Metrics are as published — state them as
written, and don't extrapolate a number to a different project.

## Enterprise Liquidity Reporting
Automated liquidity reporting for a large government pension fund, replacing
manual weekly Excel workflows with an automated production platform.

- Reporting effort: ~6 hours down to ~1 hour per run, saving ~5 analyst hours
  weekly
- Cadence: weekly to daily, with data available T+1 by 8:00 AM PT
- Eliminated a key-person dependency through automated execution
- ~90% on-time SLA for daily production pipelines
- Moved error detection upstream, before issues reached leadership dashboards

Tech: Azure, Snowflake, dbt, Prefect, Power BI, GitHub.

## Low-Latency Operational Data Store
Designed an operational data store backing customer support APIs, migrating off
Teradata.

- Reduced API response latency, improving agent productivity
- Lowered per-call infrastructure cost by removing unnecessary analytical queries
- Improved reliability and consistency of support workflows
- Established a reusable pattern for future operational data use cases

Tech: AWS Aurora, Amazon Redshift, Postman, SQL.
